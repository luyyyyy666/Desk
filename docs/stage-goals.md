# desk 阶段目标

本文将功能要求按 M0–M4 组织为可交付的阶段目标，配套 [README](../README.md) 中的产品定位、技术架构、数据规则和 A1–A8 验收标准。各阶段均为**待开发、待验收**，文档整理完成不代表功能已经实现。

## 阶段总览

| 阶段 | 目标 | 周期估算 | 完成标志 |
| --- | --- | --- | --- |
| M0 | 身份、知识底座与接地伴学 | 第 1 周 | 可使用授权知识资源进行带引用答疑 |
| M1 | 动态学情与个性化学习闭环 | 第 2 周 | 弱项识别、错题订正与针对性练习闭环 |
| M2 | 教师组卷与教学反馈闭环 | 第 3 周 | 组卷、作答、批改确认、学情补弱闭环 |
| M3 | 家校协同、学习激励与外部集成 | 第 4 周 | 基础家校反馈、激励、风险复核与 SIS 集成 |
| M4 | 全量验收与产品化交付 | 第 5 周 | 三科、移动端与部署路径完成验收 |

周期仅用于初步估算，需按工作量与依赖评估；阶段内容不足时应补齐或重排周期，不默认把必需项移到二期。高中语数英、本期不做题目难度自适应、OCR 实现可选、定时周报可选等边界继续适用。

## M0 身份、知识底座与接地伴学

**阶段目标：**建立学校身份与权限、资源接入和知识图谱基础，让学生能基于可信资料完成带引用的 AI 答疑。

**前置依赖：**无前置业务阶段；先准备虚构学校账号、授权样例资源、模型及存储配置。

**交付物：**可登录的角色入口、资源上传/解析/校正、基础审核与版本闸门、单课手工图谱、带引用伴学演示。标签和题源接入先建立基础，完整字典与采集覆盖在后续阶段持续补齐。

**完成标准：**执行 A1、A7 基础用例及 T01 的导入用例；确认引用可定位、无权资源不可检索、解析失败可处理。

### M0.1 身份与组织

支持 README 定义的角色及多角色切换、班级与任课关系管理、家长绑定、账号停用。每次角色切换重新计算可见范围。验收应使用至少两个学校、同校两个班级及家长绑定/解绑案例验证隔离。

### M0.2 多维知识资产与资源接入

- 管理题目、试卷、教案、课件、解析、优秀解法与教学案例，连接公共/外部来源、个人库与校本库。
- 支持手工录入、文件上传与拍照录入；提供可配置、具备使用授权的题源采集任务，记录区域、学校、年份、来源与使用范围，失败可重试，不默认抓取任意网站。
- 工程格式基线：PDF、DOCX、PPTX、TXT、JPG/PNG；按类型采用对应解析器，保留原文件、页码/片段、文本与媒体。公式、表格、题组和答案关系须可校正。加密、损坏、不支持的文件明确失败，不能静默入库。
- 完成“AI 解析 → 规则校验 → 教师审核”，支持重复内容提示、标签修改、来源追踪、版本与归档。典型错题或解法共享前去除学生身份信息。
- 题目核心数据包括题干、题型、选项、标准答案、解析、评分规则、材料/子题、来源、标签及审核状态；资料类资源不强制具备题目字段。
- 正式组卷只检索有权限、审核通过且有效的题目版本。已用版本保留历史快照，资源下架后不得再用于新发布任务。

**验收：**上传资料可追溯原页；错误解析可修正；未审核题检索与正式组卷隔离；校本题更新不改变已发布试卷。

### M0.3 标签体系与知识图谱

| 维度 | 数据要求 |
| --- | --- |
| 基础属性 | 学科、年级、模块；教材版本/章节作为工程扩展字段 |
| 知识维度 | 主知识点、关联知识点，支持“导数—极值判断—函数单调性”等关系 |
| 题目属性 | 难度、计算强度、灵活度；建议使用 1–5 级并维护分级说明 |
| 能力维度 | 计算、推理、综合应用等可按学科配置的能力标签及要求等级 |
| 错误标签 | 知识点模糊、条件遗漏、计算错误、思维误区等，允许多标签及教师订正 |
| 教学场景 | 日常训练、单元测试、期中期末复习、专题强化等 |

知识图谱表达题目—知识点、知识点关联/前置、题目—能力要求、学生—掌握状态和证据。知识点与边均有来源、版本及维护入口；M0 支持单课手工构建，完整范围逐步补齐三科，不能把单课演示当成三科完成。先用 MySQL 节点/边表表达图关系，不强制新增图数据库。

题目难度只能通过有版本的人工审核修改，本期不随作答统计自动变化；学生掌握和能力标签随证据动态更新，两者不可混淆。

### M0.4 AI 伴学与 Chat + RAG

围绕学生问题检索授权知识库，生成可点击回到原文页/片段的引用。采用分步提示、追问与错因解释，引导学生推理；无有效依据时明确不足，不能伪造引用。

学习模式可按任务披露策略提供分步讲解；进行中的正式考试禁止调用同题答案、解析、评分标准及替代泄题工具。后端应在检索、工具和响应阶段执行限制，不能只依赖提示词。引用访问也重新鉴权，避免学生通过原文定位绕过答案限制。

会话支持三层记忆及关联练习、弱项识别，输出结论可追溯证据。教师助手可辅助资源检索、组卷和归因，但发布试卷、确认成绩、审核资源必须由授权业务操作完成，模型不能直接更改权威记录。

## M1 动态学情与个性化学习闭环

**阶段目标：**将伴学与作答证据沉淀为可解释画像，形成识别弱项、推荐练习、订正错题、再次训练的学习闭环。

**前置依赖：**依赖 M0 的身份、知识标签、有效题目与伴学证据；本阶段提供独立练习最小作答与确定判分路径，正式班级考试在 M2 完成。

**交付物：**三层记忆、BKT 最小掌握度、动态标签、错题本、自主反馈、平行训练及推荐理由。

**完成标准：**执行 A2、A5、T04；验证弱项练习 24 小时内可见、画像能追溯 L2/L1、订正及新证据更新画像。

### M1.1 动态学情、错题本与精准训练

记录是否正确、过程、错误类型、修改情况、作答次数及学生自主反馈。综合多次作答与训练结果更新知识点掌握、能力短板、高频错误、学习变化趋势，不能凭单次错误永久判定能力。

错题本按任务、学科、知识点和错因组织；支持原题/原作答、答案披露后的解析、订正、反馈、归档和再次训练。保存错因历史及证据，教师可修正；主观反馈是待验证证据，不能自动覆盖确认成绩。

精准训练采用“学生/班级标签 × 题目标签 × 知识图谱关系”，输出推荐理由、目标知识点和能力、难度范围。支持平行题、个别学生强化和班级补弱；已掌握内容减少重复，近期重复题按策略排除，允许明确发起原题复练。

无历史数据时使用年级/章节/教师目标的基础训练并标明画像不足。无满足条件的审核题时返回缺口和可调整条件，不悄悄跨学科、超权限或使用未审核题。弱项生成至练习可见应满足 A2；存在资源缺口时记录阻塞并通知教师，阻塞不能算作 A2 达标。

## M2 教师组卷与教学反馈闭环

**阶段目标：**打通资源复用、可控组卷、任务考试、教师确认成绩与学情反馈，让教师能按班级薄弱点持续调整教学。

**前置依赖：**依赖 M0 的权限/审核题库和 M1 的画像；M0 已建立基础审核，本阶段完善个人库与校本库双向流转。

**交付物：**三类组卷入口、单题修改、试卷版本与输出、线上/拍照作答、初评复核、内部成绩回流、班级热力和预警、教研视图。成绩回流先完成内部闭环，下面保留的 SIS 适配要求在 M3 接入。

**完成标准：**执行 A3、A4、A6、A7 和 T01–T03/T05 中相应功能；计时验证热力到补弱卷发布 ≤3 分钟，验证更正与重复投递一致性。

### M2.1 教师个人库与校本库流转

教师可收藏公共或授权校本资源、上传经典题、归档历史卷/典型错题/解析，按多维标签检索。收藏保存来源和版本引用；自定义修改形成个人派生版本，不覆盖共享原件。支持去重、取消收藏、查看最近使用和复用统计。

个人资源提交共享后，由授权审核者批准进入校本库，退回时保留意见并允许修订重提。课堂产物可自动归档到个人库或校本待审核区；“自动入库”不绕过正式资源审核。校本资源可收藏回个人库，形成双向流转。教案调整、知识点关联和教学案例沉淀属于资源复用能力，不额外引入完整办公套件。

### M2.2 AI Agent 可控组卷

提供三个入口，最终转换为同一份结构化组卷约束：

1. **自然语言：**解析年级、学科、场景、知识范围、难度与强化方向；向教师展示解析参数，缺少影响生成的必填项时引导补齐。
2. **模板：**支持日常作业、单元测试、期中考试、期末复习、模拟卷；设置知识点覆盖、题型结构、难度比例、计算强度、灵活度，并补充题数、总分、时长等发布参数。
3. **按学情：**使用所选班级/学生画像，提高薄弱知识点与能力的题目覆盖，显示依据、统计时间和有效样本量。

系统从有权限的已审核题库匹配，展示知识点覆盖、题型/难度分布、计算强度、总题数、总分和选题理由。硬约束不满足则返回具体冲突与缺题数量；调整必须由教师明确操作。支持重新生成、保存草稿、排序、分值调整和预览。

### M2.3 单题控制与试卷输出

- 搜索同类题：保留当前知识点、能力和难度等约束，列出匹配候选供替换。
- 自然语言调整：“计算强度 2/5 以内”“降低难度”“更灵活”等转成可见的标签条件，并从题库重新检索候选；不把这个入口误写为默认自由编造新题。
- 自定义修改：允许直接编辑题干、答案、解析、评分和标签，或拍照上传替换题，保留原版及派生关系。实质修改后的版本必须重新审核，不能继承原审核状态。
- 调整后重算试卷约束、总分和覆盖，提供未满足条件提示。正式发布前完成内容审核与业务校验。
- 输出可保存的试卷版本、网页预览、线上任务；工程补充为支持 PDF 打印导出，学生卷与教师答案解析分开授权导出。导出失败保留草稿并可重试，公式与题组不得错位或遗漏。

### M2.4 作业、考试与作答采集

教师向授权班级或学生发布日常任务、训练或考试，配置开始/截止时间、总分、时长及答案公开规则。学生支持在线输入答案和过程、上传线下作答照片；识别结果可人工校正，原图保留用于复核。

草稿自动保存并显示保存状态；提交使用幂等标识，重复点击不得生成多次有效答卷。服务器校验身份、任务参与关系和提交期限，记录服务器时间。工程默认截止后拒绝新提交，教师可显式开放补交并留痕；不能把弱网下未送达内容显示为成功提交。

提交后修改通过补交/订正建立新记录，不覆盖原答卷。正式考试成绩仅在确认与披露规则满足后可见；练习即时反馈与考试延迟公开分开配置。任务撤回/作废保留历史和影响范围。

### M2.5 批改、成绩与回流

客观题按已审核答案及规则判分；主观题由 AI 给出分项初评、依据与置信信息，教师复核后确认。数学过程题、语文阅读/作文、英语主观题应有相应评分规则，模型结果不能直接成为正式成绩。

教师可逐题调整分数、错因和评语，系统校验分数范围与总分。确认后更新成绩册及掌握度；操作可重试且不重复计分/累计学习证据。成绩更正创建新版本，重算相应掌握度并同步报表、推荐和 SIS。

SIS 通过适配层映射学校、班级、学生、科目、考试和成绩版本，记录待同步/成功/失败并提供重试及对账。外部系统失败不回滚已经确认的内部成绩，也不能显示同步成功。

### M2.6 学情分析、教学反馈与教研

个人视图含考试分数变化、各学科能力雷达、薄弱点、知识掌握、训练记录、阶段进步及长期成长档案；每项画像结论可展开到证据。

班级视图含知识点热力/掌握率、学科能力雷达、高频错因、任务完成情况、学生预警及一键补弱卷；教师记录调整重点和后续反馈。教研视图汇总不同班级、阶段、学科与年级的变化，显示教师任课分配、年级预警、校本资源建设和导出汇报。

统计显示范围、时间窗、有效样本与更新时间。建议口径：完成率 = 有效提交人数/应完成人数；知识点得分率 = 对应有效评分的得分/可得分；正确率 = 判定正确的有效作答次数/已判定有效作答次数；掌握度与正确率分别展示。未作答、未确认、无数据不按零分或未掌握计算。跨试卷原始分不可直接比较，需标注满分或换算百分制；跨班对比保持同范围并展示样本差异。

预警规则可配置，如低掌握度、重复同类错误、未完成任务；展示触发依据和处理状态，教师可记录干预、复查、解除。阈值属于学校配置，不将原型示例人数和分数固化。

## M3 家校协同、学习激励与外部集成

**阶段目标：**让学生、家长和学校共享必要的学习反馈，补齐激励、风险复核与外部成绩同步。

**前置依赖：**依赖 M2 已确认的成绩、报告数据和有效组织关系；真实 SIS 接入需学校提供协议、映射和沙箱。

**交付物：**基础家校任务/阶段报告、成长档案、勋章积分、行为风险线索、语义查重与 SIS 适配/对账。定时家长周报保持可选；本阶段同时完成 M2“批改、成绩与回流”中定义的外部 SIS 同步。

**完成标准：**执行 T03 的 SIS 用例、T05–T06 和 A7；验证绑定/解绑、报告不含完整对话、积分幂等、风险人工复核和外部失败重试。

### M3.1 家校协同与学习激励

同步孩子学习任务、作业完成情况、阶段学习和考试报告，展示薄弱点、进步趋势与教师建议；保留阶段快照构成长周期档案。家长必须具有有效绑定关系，解绑后立即失去访问权。

定时家长周报为可选能力，可包含汇总与建议，不包含完整对话；基础阶段报告不可因此省略。报告生成和站内可见属于基础能力，外部短信/微信推送渠道另行配置，不假设已具备接口资质。

支持个人勋章墙、积分账本和积分榜。工程补充：学校配置训练、订正等积分规则，事件幂等发放；榜单默认仅展示授权班级内别名与积分，不披露成绩和能力短板。允许关闭榜单展示；积分不能修改学业成绩。

### M3.2 行为风险与语义查重

本阶段提供基础风险分析能力：仅基于平台已采集的答题时间、提交异常和答案相似度等事件生成待复核风险线索，记录规则版本、证据和教师处置；不扩展为摄像头、生物识别或自动作弊裁决。

语义查重用于资源重复识别和作答相似线索，显示相似片段与来源；相似度不等于作弊事实。学生不得访问监考风险管理与成绩写工具，AI 也不得代学生调用。

## M4 全量验收与产品化交付

**阶段目标：**完成全部功能可用性验证、问题修复与部署交付，将前四阶段的业务路径验证为可持续运行的产品。

**前置依赖：**M0–M3 必需功能已具备联调条件；学校配置、三科验收数据和目标部署环境可用。

**交付物：**

- 高中语文、数学、英语完整的资源、学习、作答、批改确认、画像、补弱和报告路径。
- 网页与 uni-app 小程序主路径，数学公式、语文/英语长题、拍照上传与弱网恢复的验证记录。
- SaaS 与单校私有化部署配置、初始化/迁移、备份恢复、升级回滚和故障排查手册。
