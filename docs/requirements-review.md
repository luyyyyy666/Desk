## 3. 发现的问题与订正

| 编号 | 原文冲突、缺口或容易产生的偏差 | 订正后的需求 |
| --- | --- | --- |
| R01 | 场景图称“自动进入校本知识库”，技术 A4 与另一个场景要求审核 | 自动沉淀为个人资源或校本待审核资源；审核通过才能正式组卷。PR-04、第 5 节 |
| R02 | 动态学情、动态资源与中期“难度标签自适应”易混淆 | 学生标签可动态更新；本期题目难度只允许人工版本审核变更；难度自适应留在中期。PR-03、第 11 节 |
| R03 | 正文功能描述较少提及伴学、初评、三层记忆和 BKT | 将技术表中的这些能力明确加入 PR-05/06/10 与第 7 节，不能只按功能介绍删减 |
| R04 | “自然语言修改”可能被误写为任意 AI 创题 | 默认转为标签约束并检索候选；人工自定义/拍照另有入口，新版本必须审核。PR-08 |
| R05 | 原题已审核后手工改题可能绕过质量闸门 | 实质修改派生草稿，重审后才允许正式发布；已发布卷固定快照。PR-08、第 5 节 |
| R06 | OCR 可选容易导致删除拍照作答/替换 | 保留照片上传、人工校正补录；OCR 实现可选，演示 Mock 明示。PR-02/08/09 |
| R07 | 家长周报可选容易扩大解释成整个家校功能可选 | 任务、完成情况、阶段学习/考试报告必需；只有定时周报可选。PR-12 |
| R08 | 三层记忆、L2/L1、BKT 缺少可开发定义 | 第 7 节给出工程解释、公式、证据版本与更正策略，明确并非原文既定细节 |
| R09 | 五周建议只列少数演示项，未完整安排三科/移动/激励等 | 保留周期建议，同时列完整发布门槛；不能用 M0–M3 演示范围取代本期功能。第 10.3 节 |
| R10 | 行为风险/语义查重/SIS 仅在排期出现 | PR-10/13 保留基础能力，风险仅用于教师复核，外部 SIS 独立适配并显式标注模拟 |
| R11 | “跨班不可见”与教研跨班汇总表面矛盾 | 普通角色不得越权跨班；授权教研/学校管理者可在授予范围汇总，服务端统一判定。第 2 节 |
| R12 | 原文未给接口、状态、事务、性能或统计口径 | 第 5–9 节补齐工程基线，新增数值标为建议；不能把建议当成原文承诺或实测结果 |
| R13 | 只有数学具体案例，可能错误收缩学科范围 | 明确语数英均需完整业务路径，语文/英语主观题有教师复核；单课 KG 只是 M0。第 1/10 节 |

| R15 | 团队表、外链图片与重复编号不适合重构 README | 移除执行人员表；README 重新编号；保留本地化来源与校验清单供后续复核 |
